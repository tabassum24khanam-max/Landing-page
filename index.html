01 Why this exists

Markets reward attention. Most people don't have any left to give.

Participating in markets currently requires a second profession. You are expected to learn technical analysis, read order flow, understand macro, manage position sizing, and then override your own instincts at exactly the moment they scream loudest.

Almost nobody has the hours. The people who do still lose to the part that can't be studied: fatigue, hesitation, conviction at the wrong time.

Nocturne removes the requirement. The analysis is continuous and mechanical. The decisions are made by a system that has no opinion it needs to defend, no position it is emotionally attached to, and no reason to look away at 03:00.

The goal was never to make you a better trader.
It was to make trading something you no longer have to do.

02 How autonomous intelligence works

One continuous loop. Ingest, interpret, decide, execute, learn.

There is no single model making a guess. Four engines run in sequence, each one constraining the next, on a cycle that never stops while a market is open.

03 The system

Four engines. Each one can stop the others.

Engine 01

Market analysis

Every instrument is decomposed into a fixed feature set on every cycle — trend structure, volatility regime, liquidity depth, cross-asset correlation, order-flow imbalance and dislocation against its own recent distribution.

Features are normalised per-instrument, so a signal on a thin small-cap and a signal on a major index pair are directly comparable. Nothing downstream ever sees a raw price.

  • Samplingcontinuous, event-driven
  • Feature set128 normalised dimensions
  • Regime states6 classified

Engine 02

Decision

Features enter an ensemble of independent evaluators. Each returns a direction and a confidence. Agreement is required — a position is only opened when conviction clears a threshold that itself moves with the current volatility regime.

Size is a function of conviction, not of enthusiasm. Weak agreement produces a small position or none at all. The most common output of this engine is no action, and that is by design.

  • Evaluatorsindependent ensemble
  • Thresholdregime-adaptive
  • Default stateflat

Engine 03

Risk management

Risk is not a filter applied after the fact. It is a hard boundary the decision engine is not permitted to cross. You define the envelope once — maximum drawdown, maximum exposure, per-position ceiling — and it is enforced mechanically.

Correlated positions are collapsed and counted as one. Exposure contracts automatically when volatility expands. If the envelope is breached, the system flattens and stops opening. It does not negotiate with itself.

  • Enforcementpre-trade, hard veto
  • Correlationnetted, not summed
  • Breach actionflatten + halt

Engine 04

Learning

Every closed position is written back with the full feature vector that produced it. The system measures which conditions its evaluators read correctly and which they consistently misread, then reweights accordingly.

Adaptation is deliberately slow. Weights move on evidence accumulated over many outcomes, never on a single result — a system that changes its mind after one loss is not learning, it is panicking.

  • Attributionper-feature, per-outcome
  • Update cadencerolling, evidence-gated
  • Guardrailshadow-validated

04 Technical architecture

Built like infrastructure, because that is what it is.

Every layer is isolated and independently observable. A failure anywhere in the stack degrades to flat and idle, never to unmanaged exposure.

06 Engineering philosophy

A system you have to watch is not autonomous.
It is just a faster way to worry.

01

Boring beats clever

Every component is deterministic where it can be and observable where it cannot. Nothing in the stack is permitted to be a black box to us.

02

Doing nothing is a decision

Most cycles end flat. The system is measured on the trades it declines as much as the ones it takes.

03

Fail to safe

Feed loss, model disagreement, venue error, our own bug — every failure path terminates in flat and idle, never in unmanaged exposure.

04

No claims we can't log

Every decision is written down with the inputs that caused it. If we can't reconstruct it, we don't say it.
